# The bundled default face: Inter, subset

The stock UI face, vendored so `r2d::load_default_font()` answers the
same look on Windows, Android and the posix dev box - no system font
walk, no missing-face fallback to the label bars.

- `Inter-Regular-subset.ttf` / `Inter-SemiBold-subset.ttf` - Inter
  v4.1 (https://github.com/rsms/inter), SIL Open Font License 1.1
  (`OFL.txt`, unmodified from the release).
- Subset to Latin + Latin-1 Supplement + Latin Extended-A + the
  typographic punctuation + the currency/tremark signs the gui's labels
  realistically draw (the ASCII bake range 32..126 always draws from
  the primary bake; the rest rides the lazy face stack), hinting
  dropped (the renderer rasterizes its own coverage):

```
pyftsubset Inter-Regular.ttf --output-file=Inter-Regular-subset.ttf \
  --unicodes="U+0020-007E,U+00A0-00FF,U+2013-2026,U+20AC,U+2122" \
  --layout-features='*' --no-hinting --desubroutinize
```

- `src/text/default_font_regular.cpp` / `default_font_semibold.cpp`
  are GENERATED byte arrays from these files (tools/embed_font.py) and
  compiled into the library - the load never touches the filesystem.
  Regenerate after changing the subsets:

```
python3 tools/embed_font.py libs/ui/assets/fonts/Inter-Regular-subset.ttf \
    --symbol inter_regular_ttf --out libs/ui/src/text/default_font_regular.cpp
```
